# 2º DAW - Diseño de Interfaces Web

Trabajos del módulo **Diseño de Interfaces Web (DIW)** de 2º de DAW, curso 2026-2027, en el IES Tetuán de las Victorias.

## Contenido

| Carpeta | Qué hay |
| --- | --- |
| [Mi Instituto Diseño Interface (Fase2)](./Mi%20Instituto%20Dise%C3%B1o%20Interface%20%28Fase2%29) | Web sobre mi experiencia como alumno del instituto. Es el prototipo que hice en Figma en la fase 1, pasado a HTML5 y CSS3 |

La carpeta tiene su propio README con el detalle de las páginas, las carpetas, las animaciones y los créditos.

## Ver la web

Está publicada con GitHub Pages en esta dirección:

**<https://wenzeladdug.github.io/2-DAW-Dise-oInterface/>**

Cada vez que subo a la rama `main` un cambio de la carpeta de la web, el workflow [`publicar.yml`](.github/workflows/publicar.yml) la vuelve a publicar sola.

## Cómo probarlo

No hay que instalar nada. Clona el repositorio y abre `index.html` en el navegador:

```bash
git clone https://github.com/WenzelAddug/2-DAW-Dise-oInterface.git
```

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid y animaciones)
- Figma, para el prototipo
