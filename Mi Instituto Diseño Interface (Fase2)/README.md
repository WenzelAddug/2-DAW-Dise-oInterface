# Mi instituto (fase 2)

Web sobre mi experiencia como alumno del IES Tetuán de las Victorias.
Proyecto de Diseño de Interfaces Web (2º DAW). Autor: Wenzel Addug.

Es la web del prototipo que hice en Figma en la fase 1, pasada a HTML5 y CSS3.

## Páginas

- `index.html`: Inicio. Quién soy, mi camino en el instituto y mi favicono.
- `centro.html`: El centro. Historia, estudios, instalaciones y cómo llegar. Maquetada con **Flexbox**.
- `estudios.html`: Mis estudios. Módulos, proyectos y lo que me llevo. Maquetada con **CSS Grid**.

Para verla solo hay que abrir `index.html` en el navegador.

## Carpetas

- `css/`: la hoja de estilos (`estilos.css`).
- `img/`: fotos del centro, logotipo, mapa y la captura de la web.
- `fonts/`: las fuentes en woff2 (Big Shoulders Display y Atkinson Hyperlegible).
- `favicon/`: el favicono en SVG y en PNG (16, 32, 64 y 180 px). `favicon-simple.svg` es la versión simplificada (sin cruceta ni botones) que se ve en la pestaña del navegador.
- `fontawesome/`: los iconos de Font Awesome Free, descargados para que funcionen sin internet.

## Qué he usado

- HTML5 con etiquetas semánticas (header, nav, main, section, article, aside, figure, footer).
- CSS3: variables, Flexbox, Grid (con grid-template-areas), media queries mobile first (576, 768, 992 y 1200 px), transiciones y animaciones sencillas.
- Menú hamburguesa para el móvil hecho solo con CSS (con un checkbox).
- Accesibilidad: textos alternativos, foco visible con el teclado, enlace para saltar al contenido y animaciones desactivadas si el usuario lo pide en su sistema.
